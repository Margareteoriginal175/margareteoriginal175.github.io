📖 What Is ClearLedger Contracts?

ClearLedger Contracts is a set of ready-made digital agreements that run on the Stellar network using a technology called Soroban. You can think of each contract as an automatic helper that keeps track of invoices, records who the parties are, holds funds safely, and releases money when agreed conditions are met — all without needing a bank or a middleman to step in.

It is built for invoice finance: a simple idea where a business that has been waiting to be paid on an invoice can turn that unpaid invoice into working cash sooner. ClearLedger handles the paperwork side automatically so everyone involved can see the same information at the same time.

Everything here is configured for the Stellar test network, which means you can safely explore and try things out without risking real money.

✨ What You Can Do With It

  • Keep a clean participant list. The participant registry records every business or person involved, so nobody is left guessing who agreed to what.
  • Follow an invoice from start to finish. The invoice lifecycle contract tracks each invoice through every stage — created, approved, financed, and settled.
  • Access USDC liquidity pools. Funding pools let participants contribute and withdraw digital dollars (USDC) that are used to finance invoices.
  • Use safe escrow coordination. Money is held in escrow and only released when the agreed conditions are confirmed by all sides.
  • Stay transparent. Every action is recorded on the Stellar test network, so records cannot be quietly changed after the fact.

🔧 Troubleshooting Common Problems

The file will not open after extracting

Make sure you extracted the ZIP file first. Double-clicking a file while it is still inside a compressed folder will not work correctly. Right-click the ZIP file and choose Extract All…, then open the file from the new folder that appears.

Windows shows a security warning

This is standard behaviour for downloaded software. Click More info on the warning box, then click Run anyway to continue.

The connection dot stays grey or red

Check that your internet connection is working, then close and reopen the application. The Stellar test network is occasionally busy, so waiting a minute and trying again usually resolves it.

The download stops partway

Large downloads can pause on slow connections. Delete the partial file from your Downloads folder and start the download again from the link above. Using a wired connection or moving closer to your Wi-Fi router often helps.
